# Hayeren Stories — видеопроизводство

Короткие мягкие видео для YouTube-канала об армянских словах, буквах и фактах.
Каждый выпуск — одна история слова, которую рассказывает «говорящий» герой-предмет.

## Формат выпуска (6 глав)
1. Предыстория
2. Знакомство со словом
3. Яркое историческое событие (быль, герой, эпос)
4. Связка и мягкий подход к современности
5. Современное значение и заключение
6. Слоган («Хорошо, когда знаешь») и призыв подписаться

Видео 16:9, 1280×720, 24 к/с, пастельная 3D-графика, у каждой главы свой фон, маскот двигается и жестикулирует, тихая музыка.
Языки: русский (ru) и испанский (es).

## Как собрать выпуск
Нужны Python 3, `ffmpeg`, `numpy`, `Pillow`, `espeakng-loader`, шрифт DejaVu Sans.

```bash
cd episodes/001-nur-granat
pip install numpy pillow espeakng-loader piper-tts
python3 make_video.py ru nur_granat_ru.mp4 work     # русская версия
python3 make_video.py es nur_granada_es.mp4 work    # испанская версия
PREV=4,30,60 python3 make_video.py ru prev work --preview   # только контрольные кадры
```

Рабочая папка `work/` получает промежуточные файлы. Время рендера ≈ 3–4 мин на версию.

## Голос
Основной — нейросетевой Piper (мужские голоса: `ru_RU-denis-medium`, `es_MX-claude-high`).
Модели весят ~60 МБ каждая и в репозиторий не входят: скачайте `./voices.sh`
(нужен доступ к `huggingface.co` и `us.aws.cdn.hf.co`), затем:

```bash
HAYEREN_VOICES=$PWD/voices python3 make_video.py ru out.mp4 work
HAYEREN_VOICE_RU=ru_RU-dmitri-medium HAYEREN_VOICES=$PWD/voices python3 make_video.py ru out.mp4 work   # другой голос
```
Без моделей используется запасной синтетический голос eSpeak NG.
Чтобы использовать запись настоящего диктора, положите в `work/` по одному WAV на реплику:
`ru_01.wav … ru_14.wav` (`es_01.wav …`). Тайминги глав, субтитры и движение рта
подстроятся под длину и громкость записей.

## Фото и кадры
Генератор умеет показывать ваши фото и кадры в рамке главы 3: положите изображения в `assets/` рядом
с `make_video.py` (или укажите `HAYEREN_ASSETS=/путь`). Файлы идут по имени (`1_*.jpg`, `2_*.jpg`…),
меняются плавно, с лёгким «Кеном Бёрнсом». Без файлов показывается нарисованная иллюстрация.
**Важно:** кадры фильмов и фотографии защищены авторским правом — используйте только лицензированные
материалы или файлы из открытых источников (укажите лицензию и автора в описании ролика).

## Новый выпуск
Скопируйте папку выпуска, замените реплики `LINES`, реквизит и палитры в `make_video.py`
и сценарий в `SCRIPT.md`. Факты перед публикацией проверяйте по источникам
(см. раздел «Что нужно проверить» в сценарии).
