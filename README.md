# Hayeren Stories — видеопроизводство

Короткие мягкие видео для YouTube-канала об армянских словах, буквах и фактах.
Каждый выпуск — одна история слова, которую рассказывает «говорящий» герой-предмет.

## Формат выпуска (6 глав)
1. Предыстория
2. Знакомство со словом
3. Яркое историческое событие (быль, герой, эпос)
4. Связка и мягкий подход к современности
5. Современное значение и заключение
6. Слоган («Хорошо, когда знаешь») и призыв подписаться

Видео 16:9, 1280×720, 24 к/с, пастельная графика, Арарат на фоне, тихая музыка.
Языки: русский (ru) и испанский (es).

## Выпуски
| № | Слово | Рассказчик | Папка |
|---|-------|------------|-------|
| 001 | Նուռ («нур», гранат) | гранат | `episodes/001-nur-granat/` |

## Как собрать выпуск
Нужны Python 3, `ffmpeg`, `numpy`, `Pillow`, `espeakng-loader`, шрифт DejaVu Sans.

```bash
cd episodes/001-nur-granat
pip install numpy pillow espeakng-loader
python3 make_video.py ru nur_granat_ru.mp4 work     # русская версия
python3 make_video.py es nur_granada_es.mp4 work    # испанская версия
PREV=4,30,60 python3 make_video.py ru prev work --preview   # только контрольные кадры
```

Рабочая папка `work/` получает промежуточные файлы. Время рендера ≈ 3–4 мин на версию.

## Голос
По умолчанию голос синтезируется локально через eSpeak NG — это запасной вариант,
звучит синтетически. Чтобы использовать настоящую запись диктора, положите в `work/`
по одному WAV на реплику: `ru_01.wav … ru_14.wav` (`es_01.wav …`). Тайминги глав,
субтитры и движение рта подстроятся под длину и громкость записей.

## Новый выпуск
Скопируйте папку выпуска, замените реплики `LINES`, реквизит и палитры в `make_video.py`
и сценарий в `SCRIPT.md`. Факты перед публикацией проверяйте по источникам
(см. раздел «Что нужно проверить» в сценарии).
